**# College of Information and Computer Studies (CICS) Website Mockup

## 📌 Project Overview

This project is a modern and responsive website mockup developed for the **College of Information and Computer Studies (CICS)** of **Interworld Colleges Foundation Inc.**

The website is designed to provide students, faculty members, and visitors with an organized and accessible online platform where they can learn more about the college, its programs, activities, announcements, and other important information.

This project was created as a **website mockup for academic purposes** and focuses on the user interface (UI), user experience (UX), and overall visual presentation of the college.

---

## 🎯 Project Objectives

- Create a modern and professional website for the College of Information and Computer Studies.
- Provide users with easy access to important college information.
- Showcase the programs, activities, events, and announcements of CICS.
- Create a responsive and user-friendly interface.
- Organize college information into clear and accessible sections.
- Provide a foundation that can be further developed into a fully functional website.

---

## ✨ Website Features

The website mockup includes the following sections and features:

- 🏠 **Home Page**
  - College introduction
  - Welcome section
  - Featured information
  - Latest announcements
  - Upcoming events

- 🏫 **About CICS**
  - Information about the college
  - College overview
  - Mission and vision

- 🎓 **Programs**
  - Information about academic programs and courses

- 📰 **News and Announcements**
  - College updates
  - Important announcements
  - Featured news

- 📅 **Upcoming Events**
  - Academic events
  - College activities
  - Student activities

- 📞 **Contact Information**
  - College contact details
  - Other relevant information

- 📱 **Responsive Design**
  - Designed to work across different screen sizes and devices

---

## 🛠️ Technologies Used

- **React.js** – Used to build the website's user interface and components.
- **Vite** – Used as the development and build tool for the React application.
- **JavaScript (JSX)** – Used to create interactive components and website functionality.
- **CSS** – Used for styling, layout, responsiveness, and visual design.
- **HTML** – Used as the foundation of the web application.
- **Lucide React** – Used for icons and visual elements.
